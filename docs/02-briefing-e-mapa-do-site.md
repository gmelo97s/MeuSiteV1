## 4. Direção visual

- **Base**: noite quente (quase preto amarronzado), não o preto frio da APUS.
- **Luz**: âmbar `#FBCC2F` → laranja `#F9942F` → brasa `#FF4D1A` (gradiente M4).
- **Blocos de cor** quando a luz acende: âmbar, vinho, creme e um azul-cobalto de contraste (energia Linktree).
- **Tipografia**: display grotesca pesada para títulos (energia Linktree) e texto fino e elegante de apoio (leveza APUS).
- **Movimento**: tudo com `cubic-bezier(.22,1,.36,1)`, revelar com desfoque, celular fixo no desktop, versão leve no celular, respeitando "reduzir movimento".

## 5. Stack

- **Vite + JavaScript puro** (sem framework: é uma landing, precisa carregar rápido).
- **GSAP + ScrollTrigger** para as cenas fixas e **Lenis** para a rolagem suave.
- Vídeos em `.mp4`/`.webm` curtos (< 3 MB cada), com carregamento sob demanda.
- Deploy na **Vercel** a partir deste repositório (cada push publica).
